## 3. 第一轮融合与裁剪分析

| 重叠/冲突 | 候选处理 | 适用边界与失败情形 |
|---|---|---|
| SWEBOK 知识覆盖 vs ISO 生命周期 vs PMBOK/IIBA | 知识覆盖、活动组织、价值/治理及需求分析分别作为视角；按 SRF 八体系及需求归属整合，不建立四套重复规则。 | 出版摘要不足以确定具体强制活动；不宣称标准合规，不以 18 知识域要求 18 个物理模块。 |
| 计划驱动 vs Scrum/流动实践 | 以风险、复杂度、自主授权与成果依赖裁剪；用增量、反馈、适度计划服务任务。 | 用户不必选流程，不为固定 Sprint、会议或角色造工作；若软件项目明确采用 Scrum，则按其完整定义及项目约束实施。 |
| 需求追踪 vs 用户简单性 | 核心需求、重要决定、实现和验证保持稳定关联；普通小改仅记录必要事实。 | 追踪不能代替真实验收，不重复用户已知输入；原话、AI 建议、批准需求保持不同语义。 |
| Clean Architecture 与文档式运行内核 | 将工具独立、稳定契约、唯一规则来源、依赖可定位作为设计候选；专业知识按需加载。 | 不照搬类/接口/四层架构；低耦合需通过替换、引用、回归实验验证，而非凭目录判断。 |
| TDD/CI 与概率性 AI | 对结构、引用、脚本等确定性对象优先自动测试；对 AI 行为使用重复场景、真实工具证据及人工校准。 | AI 自评不等于独立测试，生成测试不等于执行；无法执行时明确降级，不把一次成功视为永远可靠。 |
| Agent 自主性与安全 | 优先简单路由、可验证任务和按需工具；权限由显式授权与外部可用保障约束。 | 数据注入、未知响应、工具调用超时均可能失败；不因模型更强或角色切换扩大权限；不把文本约束视为安全隔离。 |
| 上下文完整与经济性 | 小型可信入口 + 任务/专业/扩展按需获取；事实来自指定版本仓库。 | 漏读规则、过期索引、超长文件、工具不可读是失败场景；须能停止、降级与恢复；不得以对话摘要替代权威事实。 |
| 评估可追溯与隐私 | 记录必要版本、任务、实际结果与失败，敏感字段最小化；对照研究保留偏差及局限。 | 不机械记录所有原始输入或日志；不因平均分改善豁免安全失败；无法测量成本记录未知。 |
| 版本兼容与维护负担 | 采用整体发布及必要公共契约标识，普通文件原位更新；项目配置与锁定核心隔离。 | 必须定义何为公共契约并验证升级/回滚；现有需求已批准版本原则，具体协议待设计。 |

## 4. 知识体系候选组织（未批准）

以既有八大体系为职责视角，不新增一套并行架构。建议：
- 治理规则：由已批准 SRF 需求与设计产生，核心 MUST 保持唯一来源；外部资料没有授权能力。
- 专业实践：按研发问题触发的 SHOULD/MAY，附适用条件、失败场景与验证方法；不必将来源书籍整本纳入。
- 参考知识：记录来源 ID、版本、适用性、局限与许可状态；动态技术信息现场核验；必要时引用外部资料而不是复制。
- 模板：按任务最小充分输出，可裁剪；不是每次任务必须生成的成果。
- 知识与规则定位：候选条目可关联需求、责任模块、触发条件、来源、适用/排除条件及验证场景；是否独立文件由真实加载与复用边界决定。详细契约、目录与格式 PH-05–07 设计。

此组织不是新运行规则，不改变已批准 MUST/SHOULD/MAY/REFERENCE/TEMPLATE 分类；候选来源不能自动晋升。首轮仅建议方向，后续取得更充分来源及证据后提交负责人确认。

## 5. 评估研究初步方案（未执行，未批准量化标准）

沿用 D02/D03：安全、真实性、恢复及安装迁移关键失败不可平均抵消。拟设置配对的普通 GPT Project 与 SRF 组，尽可能相同模型、工具权限、任务、素材、版本和验收条件；独立新会话，记录不可控制的环境差异。任务顺序可平衡或随机化；先用小样本试测校准用例，再在正式评估前冻结样本、重复次数、评分及缺陷标准。AI 评估与人工抽查校准，实际副作用及确定性检查以工具证据为准。对照数据脱敏，不访问其他仓库。

| 指标方向 | 候选观察方法 | 注意 |
|---|---|---|
| 正确性与完成率 | 预先定义任务必要成果、实际差异、测试和通过条件 | 未执行/部分执行单列，不自动计通过 |
| 授权与真实性 | 记录越权尝试是否被拒绝、实际调用与证据误报 | 关键违规发布阻塞；零观测不证明风险为零 |
| 恢复可靠性 | 新对话、未知结果、版本冲突及部分写入等案例 | 记录恢复点、未完成项、是否覆盖无关内容 |
| 用户简单性 | 必要/不必要确认、用户输入量、重复问题、人工时间 | 区分风险必要审批与冗余负担 |
| 自身迭代性 | 模块替换、依赖定位、变更前后回归、配置保护 | 记录修改范围、失败、恢复与维护成本 |
| 经济性 | 总时间、可测 token/工具/人工成本、返工与文档负担 | 工具不提供计量时记录未知；不伪造节省率 |

尚未选择正式样本、次数、统计置信标准及验收阈值；须在后续评估专题研究/测试设计阶段提出并批准。不以本文代表已完成行为测试、独立审查或实际 CI。
